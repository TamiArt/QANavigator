# Визуальная база знаний

Исходные PNG используются приложением без перерисовки, перекодирования и изменения бинарного содержимого. Имена файлов сохранены такими, какими они были добавлены в репозиторий: это исключает бинарные rename-конфликты в pull request.

Нормализованные логические названия, категории и связи с каноническими темами задаются только текстовым файлом `src/app/handbook-visual-topics.ts`. Несколько изображений одной темы показываются в одной статье базы знаний и не создают дубли.

В списке изображения загружаются лениво и визуально уменьшаются средствами браузера. По клику открывается тот же исходный PNG в полном разрешении с масштабированием — отдельная изменённая копия изображения не создаётся.

При добавлении материала:
1. не изменяйте существующий бинарный файл;
2. добавьте связь с канонической темой и содержательный русский `alt`;
3. новую тему создавайте только при отсутствии подходящей существующей;
4. проверьте факты и орфографию — инфографика не является нормативным источником.
