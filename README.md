# QA Navigator

**QA Navigator** — браузерное QA-пространство для работы с проектами, требованиями, тест-дизайном, ручными проверками, тестовыми данными, SQL, QA-документацией и обучением.

Приложение построено на React, TypeScript и Vite. Данные текущей версии сохраняются локально в браузере; Database Workbench использует SQLite через WebAssembly (`sql.js`). Внешние AI-провайдеры OpenRouter/Gemini присутствуют как опциональная возможность и требуют пользовательского ключа. Основные сценарии должны оставаться доступны без AI.

## Текущие разделы

- Рабочее пространство проектов
- Мастер для новичка
- Анализ требований
- Тест-дизайн
- Выполнение тестов и баг-репорты
- Раздел автотестов
- Релизный отчёт
- Генератор тестовых данных
- Database Workbench (SQLite/WASM в браузере)
- База знаний QA и Learning Mode
- QA-документация
- Настройки, резервное копирование и импорт/экспорт

## Запуск и проверка

Требования: актуальная LTS-версия Node.js и npm.

```bash
npm install
npm run dev
```

Основная проверка проекта:

```bash
npm run verify
```

Отдельная production-сборка:

```bash
npm run build
```

Состав проверок команды `verify` зафиксирован в `package.json`. На момент актуализации документации он включает проверки handbook/Learning Mode, инфографик, навигации, Database Workbench, тест-дизайна, storage, project context, документации, backup, TypeScript и production build.

## Границы текущей реализации

- Database Workbench — браузерная SQLite-среда на WASM. Она не является прямым подключением к PostgreSQL или MySQL.
- Встроенного полноценного HTTP/API-клиента, OpenAPI Studio, Log Analyzer и интеграционного обмена с Test IT пока нет.
- База знаний содержит учебные материалы об инструментах; наличие упоминания инструмента не означает наличие интеграции с ним.
- Текущие AI-провайдеры требуют пользовательских ключей. Их тарифы и бесплатные квоты не гарантируются.
- Текущий storage использует localStorage и слой валидации/backup. IndexedDB запланирована для будущих больших наборов данных, но ещё не является основным хранилищем.
